= UserGroup

The user_group gem provides support for user accounts and DRI policy
and access controls (which is stable to develop against).

The gem contains the functionality for user management, group management
and also provides a shared code base for the security system in both
admin and public hydra heads. Session management and authentication is
delt with through Devise.

* Ability to get/set permissions on the asset for read and update operations.
  - public
  - restricted - groups, users
* Ability to get/set the embargo date.
* Objects inherit permissions from collections/sub-collections.
* Group management (provided by user_group gem)(users can request access to restricted groups which provide access to restricted objects)
* User account creation and management
  - Support functionality (password recovery etc...)
  - User profiles

== Install Gem:

1. gem install user_group-<version>.gem

== Use In Rails Application:

To install this engine you must first go to the rails application in
which this will be included. Perform the following actions:

1. Edit your gemfile to include user_group (gem 'user_group') Note: user_group includes devise by default.
2. bundle update
3. rake user_group:install:migrations
4. rake db:migrate
5. edit your applications db/seeds.rb file to include UserGroup::Engine.load_seed
6. rake db:seed
7. Edit the routes file (config/routes.rb) to include the line
  mount UserGroup::Engine => "user_groups"
  where "user_groups" is the path you want to mount the engine at.
8. Start the server and go to localhost:3000/user_groups and login as email: admin@example.com, password: password
9. Ensure your application provides a main_app route

To enable the forgot password link you must set up mailer add the following

  config.action_mailer.default_url_options = { :host => 'localhost:3000' }

to config/environments/development.rb

This will show the link the user must go to in the console.
